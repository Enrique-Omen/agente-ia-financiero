# Agente de IA financiero · Ciencia de Datos Aplicada a la Economía

Luis Enrique López Salazar · Ibero León · Prof. Rubén Miguel Rodríguez Rangel · Otoño 2026

Práctica de Deep Learning para Finanzas (BTC/USDT, datos públicos de MEXC) y el agente que la usa.

- `avances/`: cuadernos ejecutados de los avances 1 a 4 (capítulos 7 a 10).
- `agente/backend/`: API en FastAPI que calcula las variables, da el pronóstico del modelo y simula operaciones en papel (sin ninguna ruta de órdenes reales). Cómo instalar y correr: `agente/backend/README.md`.
- `agente/CONTRATO.md`: las variables y el formato que comparten el entrenamiento y la API.
